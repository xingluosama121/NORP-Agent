# NORP Pet Bridge · 桌面小伙伴插件 🐾

**v2.1.0** —— 桌面小伙伴已**完整内嵌**为本插件的一部分，不再依赖任何外部启动脚本。

> 一只可以在桌面上活动的二次元小伙伴（优香）：
> 单击互动、双击唤起 NORP、右键菜单、空闲散步/奔跑/休息、贴墙半隐藏、
> 金币/心情/饱食度养成、**好感度/陪伴天数/名字自定义/节日问候**、
> 背包商店、任务自动播报，还能在对话里直接指挥它说话做表情。

---

## ⚠️ 环境要求（用户必读）

| 依赖 | 说明 | 必需？ |
|------|------|--------|
| **Python 3.8+** | 宠物是独立进程，插件用 `pythonw` 拉起 | ✅ 必需 |
| **tkinter** | Python 标准库自带（Windows 官方安装包默认包含） | ✅ 必需 |
| **Pillow (PIL)** | 真 alpha 透明渲染 + 平滑缩放 | ⭐ 强烈建议 |
| **Windows 10/11** | 依赖分层窗口（UpdateLayeredWindow）实现透明 | ✅ 必需 |

> 📌 **没有 Pillow 也能运行**（自动降级为 Tk 渲染），但透明背景会变成灰色块、贴墙半隐藏效果会打折，建议安装：
> ```bash
> pip install pillow
> ```

## 📦 安装方法

1. 将 `norp_pet_bridge/` 整个文件夹放入 NORP 的插件目录（如 `plugins/`）；
2. 在 `config.json` 的 `plugin_dirs` 中加入该目录（如 `["plugins"]`）；
3. 重启 NORP —— 宠物自动出现在桌面右下角。

> ⚙️ **安全配置注意**：请保持默认插件安全设置
> （`plugin_security_import_restrict` 保持 `"off"`）。
> 本插件需要 `subprocess` 拉起宠物进程，若开启 `safe`/`strict` 导入限制会导致插件无法加载。

## 🔌 生命周期联动

- **NORP 启动** → 宠物自动唤出（插件加载即拉起 + 15 秒看门狗守护）
- **NORP 退出** → 宠物说晚安 → 优雅退出（记住位置）
- **任务钩子** → 开始 / 完成 / 出错 / 超时 / 提问，宠物自动冒泡播报
- **崩溃自愈** → 宠物进程意外死亡后自动复活

## 🛠 对话中可用的工具

`pet_say`（让宠物说话）/ `pet_action`（做表情）/ `pet_status`（查状态）/
`pet_launch`（叫出来）/ `pet_quit`（收回去）
—— 直接说「让宠物说…」「让它睡觉」「叫它出来」即可。

### 活动范围 & 贴墙（设置面板可调）

| 行为 | 说明 |
|------|------|
| 范围限制 | 人物边缘检测：顶部不越屏、底部 1/2 处为界、左右边缘贴边即停 |
| 贴墙半隐藏 | 拖到左/右边缘 → 旋转 45° 头朝屏内，半边藏墙里；右键/拖出/30 分钟无聊后出来 |
| 自动贴墙 | 走路撞边自动躲进墙里，待 20~40 秒自己出来（设置可关） |
| 自由移动 | 关闭后取消物理位移，只播放动作原地待着 |

### 行为设置（右键 → ⚙ 设置）

- ✅ 允许贴墙 / 靠近墙面时自动贴墙 / 允许自由移动 / 双击打开 NORP / 空闲随机走动
- 🏷 小伙伴设置：名字自定义 + 相伴天数/好感度一览

## 📁 目录结构

```
norp_pet_bridge/
├── manifest.json        # 插件清单（v2.0.0，permissions: network）
├── plugin.py            # 插件入口：5 个工具 + 生命周期钩子（15 钩子全兼容）
├── embedded.py          # ★ 宠物进程托管器：启动 / 退出 / 崩溃自愈
├── pet_core/            # ★ 宠物本体
│   ├── pet.py           #   宠物程序（零第三方依赖核心，PIL 可选增强）
│   ├── alpha_render.py  #   真 alpha 分层渲染（Windows）
│   ├── assets/          #   优香全部动画帧 + 图标（含拖拽/睡觉/喂食/打招呼/摸头帧）
│   └── __init__.py
├── _test_embedded.py    # 托管器回归自测
└── _test_plugin_load.py # 插件加载回归自测
```

## 🔒 技术说明

- 宠物控制通道：`127.0.0.1:17778`（仅本机回环）；NORP 本地 API：`127.0.0.1:17777`
- 单实例锁：端口 47771 防多开
- 素材查找顺序：`pet_core/assets/` → 工作区 `youxiang/`（兜底）
- 配置 `pet_core/config.json` 首次运行自动生成
