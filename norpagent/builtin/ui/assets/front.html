🔒 Plugin Security

Code Audit: Scans plugin source for dangerous patterns before loading.
Import Restriction: Limits which Python modules plugins can import.

🧩 进程隔离

插件在独立子进程中运行，严禁直接挂载到主进程。进程内模式仅在开发调试时使用。

🔏 签名 / 来源校验

对插件源码做 Ed25519 签名验证。受信任签名的插件放宽导入限制；未签名插件默认严格限制；被篡改插件直接拒绝。

🌐 网络策略（SSRF 防护）

任何非「全部网络」的策略都会拦截内网 / 环回 / 元数据地址。

🛡️ 插件工具调用审批

开启后，调用插件提供的工具前需人工确认。原生内置工具的确认请在「设置 → 原生工具确认」中配置。
